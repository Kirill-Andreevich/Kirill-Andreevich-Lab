# 🗺️ План развития (Roadmap) & Технический долг

Этот документ описывает пройденные этапы развертывания Enterprise Homelab, текущий фокус разработки и долгосрочные архитектурные цели.

---

## ✅ Фаза 1: Фундамент и Сеть (Выполнено)
Создание надежной базы Infrastructure-as-Code и сетевой связности.

- [x] **IaC Provisioning:** Описание KVM-виртуальных машин через Terraform-модули (инфраструктурный слой и слой кластера).
- [x] **Zero-Touch Inventory:** Динамическая генерация `hosts.ini` для Ansible налету из стейта Terraform.
- [x] **Сеть и IPAM:** Настройка OpenWrt (Xiaomi AX3600) — DHCP MAC-привязки, L2-маршрутизация и Firewall-пробросы (DNAT) для RDP, RustDesk и Nginx Proxy Manager.
- [x] **Управление секретами:** Внедрение Ansible Vault для защиты чувствительных данных и паролей.

---

## ✅ Фаза 2: Кластер и Storage-слой (Выполнено)
Сборка Kubernetes и интеграция с внешним ZFS-хранилищем.

- [x] **K8s Bootstrap:** Автоматизация установки containerd, kubelet/kubeadm и инициализации кластера v1.31 с помощью Ansible.
- [x] **Сетевая фабрика:** Развертывание Flannel CNI и MetalLB (с выделенным пулом `192.168.1.200-239`).
- [x] **Storage Integration (CSI):** Успешная интеграция `democratic-csi` с API TrueNAS SCALE (Ryzen 9700X). Кластер умеет динамически нарезать датасеты в ZFS (пул `NVME`) и отдавать их подам по iSCSI.
- [x] **Резервное копирование:** Настроен S3-бэкап через `restic` на защищенный RAID5-пул TrueNAS с дедупликацией.

---

## 🔄 Фаза 3: Техдолг и Миграция сервисов (Текущий фокус)
Оптимизация архитектуры и исправление накопившихся race-conditions.

- [ ] **Оптимизация RAM на TrueNAS (Миграция):** Полный отказ от встроенных приложений (`.ix-apps` / docker) на TrueNAS. Перенос Jellyfin, Nextcloud и Nginx Proxy Manager внутрь Kubernetes (манифесты готовы в `kubernetes/apps/`). Это освободит 32 ГБ RAM для ZFS ARC-кэша.
- [ ] **Fix Loki Race Condition:** Изменить манифест `loki-values.yaml`, добавив аннотацию `metallb.universe.tf/loadBalancerIPs: 192.168.1.206`. Сейчас IP балансировщика выдается динамически, из-за чего Promtail шлет логи вникуда.
- [ ] **Устранение конфликта iSCSI:** Удалить/отключить устаревший Ansible плейбук `04_setup_iscsi_disk.yml`, который делает ручное монтирование дисков, так как теперь эта задача полностью делегирована `democratic-csi`.
- [ ] **Fix Alertmanager:** Исправить таргет тестирования алертов в `Makefile` (сейчас он ищет LoadBalancer IP, но Alertmanager развернут как ClusterIP).

## 🔜 Фаза 4: CI/CD Pipeline & GitOps (Запланировано)
Переход от запуска скриптов с локальной машины к полноценному пайплайну.

- [ ] **Развертывание GitLab:** Довести до ума ВМ `gitlab-srv` (уже инициализирована Terraform) с помощью плейбука `03_setup_gitlab.yml`.
- [ ] **GitLab Runners:** Развернуть раннеры внутри Kubernetes для выполнения сборочных задач.
- [ ] **GitOps Pipeline:** Перенести логику команд `make all`, `terraform apply` и `ansible-playbook` внутрь пайплайна `.gitlab-ci.yml`. Инфраструктура должна обновляться автоматически при пуше в ветку `main`.

Использование всей мощи архитектуры Zen 5 и флагманских GPU для локальных нейросетей.

- [ ] **K8s Device Plugins:** Настройка проброса видеокарт внутрь контейнеров кластера.
- [ ] **NVIDIA Passthrough:** Проброс RTX 4090 на узле `Node .22` (Compute, Ryzen 9950X3D).
- [ ] **AMD Passthrough:** Проброс Radeon RX 9070 XT на узле `Node .23` (Workstation, Ryzen 9800X3D).
- [ ] **Развертывание LLM:** Завершение настройки роли Ansible `ai_stack` для деплоя Ollama и модели DeepSeek-R1 (14b) с аппаратным ускорением на железе.
